# UX Polish Plan — pnetto.com

Audit performed against the current codebase. The design language (mono `code saver`, dark default, warm gold accent, generous container, photo-grid hero) is sound. Every recommendation here keeps that language intact and only refines the *quality of motion, hierarchy, feedback, and perceived speed*.

Notation: file paths are absolute, change targets are exact selectors/lines, and durations/easings are tasteful (160–280ms for most state changes, 400–600ms for entrances).

#### 2. Prefetch in-viewport links on idle
- **File:** new `/Users/pedronetto/Development/projects/pnetto.com/design-system/src/js/prefetch.js`, included from `index.js`
- **What to change:** ~30 lines of `IntersectionObserver` + `requestIdleCallback`:
  ```js
  if ("IntersectionObserver" in window && "requestIdleCallback" in window) {
    const seen = new Set();
    const io = new IntersectionObserver((entries) => {
      for (const e of entries) {
        if (!e.isIntersecting) continue;
        const href = e.target.href;
        if (!href || seen.has(href) || new URL(href).origin !== location.origin) continue;
        seen.add(href);
        requestIdleCallback(() => {
          const l = document.createElement("link");
          l.rel = "prefetch"; l.href = href; document.head.appendChild(l);
        });
        io.unobserve(e.target);
      }
    });
    document.querySelectorAll("a[href^='/'], a[href^='./']").forEach(a => io.observe(a));
  }
  ```

- **Why it matters:** Combined with View Transitions, navigation feels instantaneous because the next document is already in the HTTP cache by the time the user clicks. Zero CLS, zero perceived TTFB.
